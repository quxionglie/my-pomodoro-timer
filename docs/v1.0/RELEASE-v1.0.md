## PomodoroTimer v1.0

PomodoroTimer 是一款简洁的 macOS 菜单栏番茄钟，帮助你专注工作、学习与创作。

### 主要功能

- 支持 15、30、45、60、90 分钟专注计时
- 计时开始后自动收起主窗口，仅保留菜单栏图标
- 菜单栏图标实时展示当前计时进度
- 时间到后显示置顶提醒并播放提示音
- 自动记录每日开始、手动停止和完成次数
- 支持将完整统计记录导出为 Markdown
- 支持英文、简体中文和繁体中文
- 计时时长、语言和统计数据均会自动保存

### 安装方式

1. 下载 `PomodoroTimer-v1.0-macOS.zip`
2. 解压后，将 `PomodoroTimer.app` 拖入“应用程序”文件夹
3. 双击启动应用

应用已使用 Apple Developer ID 签名并通过 Apple 公证，可放心安装。

### 系统要求

- macOS 14.0 或更高版本

## English

PomodoroTimer is a simple macOS menu bar Pomodoro timer designed to help you stay focused while working, studying, or creating.

### Highlights

- Focus sessions of 15, 30, 45, 60, or 90 minutes
- Automatically hides the main window when a session starts
- Displays session progress through the menu bar icon
- Shows an always-on-top reminder and plays a sound when time is up
- Tracks daily starts, manual stops, and completed sessions
- Exports complete session history as Markdown
- Supports English, Simplified Chinese, and Traditional Chinese
- Automatically saves timer duration, language, and statistics

### Installation

1. Download `PomodoroTimer-v1.0-macOS.zip`
2. Unzip it and move `PomodoroTimer.app` to the Applications folder
3. Double-click the app to launch it

The app is signed with an Apple Developer ID certificate and notarized by Apple.

### Requirements

- macOS 14.0 or later
